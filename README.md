# 4M AUTOTECH / Khawaja Garib Nawaz Car Detailing

Official website for **4M AUTOTECH & Khawaja Garib Nawaz Car Detailing** — New Delhi's Premier Car Care Products & Detailing Studio.

## 🚀 Features

- **Responsive Multi-Page Design**: Homepage, Products Catalog, Services Showcase, and Contact Page.
- **Data-Driven Architecture**: All products, services, and business info configured via modular JS files (`config.js`, `products.js`, `services.js`).
- **Interactive Product Catalog**: Real-time category filtering and detailed pop-up product modal.
- **Direct Enquiries**: 1-click WhatsApp and Phone call CTAs with pre-filled product/service messages.
- **Custom Vector Visual Assets**: 3D bottle mockups and detailing graphics for all 18 products and 7 services.
- **SVG Icon System**: Zero third-party icon font dependencies.

## 📁 Project Structure

```
├── index.html            # Homepage
├── products.html         # Products Catalog & Modal
├── services.html         # Detailing Services & Car Spa Package
├── contact.html          # Studio Location, Hours & Contact
├── css/
│   └── style.css         # Dark automotive design system
├── js/
│   ├── config.js         # Business info & WhatsApp URL helpers
│   ├── products.js       # 18 product data records
│   ├── services.js       # 7 detailing services & Car Spa package
│   └── icons.js          # SVG Icon Library
└── assets/
    └── images/
        ├── products/     # Vector 3D product bottle mockups
        └── services/     # Detailing service graphics
```

## 🛠️ Getting Started

Open `index.html` in any modern web browser or run with any static web server (e.g. Live Server).
